    Basics

    Units

    Every size in a layout is in layout units, Bitwig's own. Bitwig draws a unit as screen pixels at your UI scale (), so a layout looks the same at any scale. The preview draws at that scale too.

    Height: fixed by Bitwig, the one real limit

    Every device in the chain has the same height. Here it is units (what the framework logs as height available in Bitwig's log; set another under Available). Bitwig's plug-in toolbar takes of it unless "toolbar": false, leaving for the layout. A taller layout is zoomed down to fit, but not below : so at most units of layout fit, and beyond that the bottom is cut off. Put controls side by side in rows to keep a layout short.

    The layout's height, top to bottom: padding (), the title line (the plug-in's name and, with pages, the page tabs, Bitwig's row height ; leave it out with "title": false), a gap of , the columns (as tall as the tallest), the footer gap and footer row, then 4 units of the framework's spacing and the bottom padding.

    Width: free

    There is no maximum width: the framework sets the device body to exactly the layout's width, and the device chain scrolls sideways. The width is width if you give one, else the sum of the columns' widths, gaps and padding when every column has a width, else what the content needs.

    Columns, rows and cells

    • Columns sit left to right, apart (gap); a divider goes in the middle of its gap. Items in a column are apart. A column with a width is exactly that wide and centres its items; without one it is as wide as its widest item.
    • Rows put items side by side, apart. A row with a fixed width (its own, or its column's) shares it in equal cells.
    • Knobs at a theme size are Bitwig's knob () with the label above and the value under it, apart; a label is its font's height (Default: ). A knob with a number size is a fixed cell: its label line, the knob at exactly that size, and its value line, as wide as its cell. The label line's height comes from its font, not from the knob's size: a 65 knob and a 34 knob in Default have the same label line (), unless the layout sets label_height. So a knob's ring starts that label line plus below the cell's top, plus the ring's small inset in the knob's box. Select an item to see these edges as guides with their exact heights, and use Align in the inspector to line one item up with another.
    • A background adds units of padding around its item.

    min_resolved

    A reference to a parameter the plug-in doesn't have makes the whole layout fall back to Bitwig's own page. "min_resolved": 80 lets 80% of references be enough: the items whose parameter is missing are left out (an envelope is drawn empty), and the layout falls back only when fewer match.
